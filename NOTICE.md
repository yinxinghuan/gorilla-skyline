# Attribution

Skyline Gorillas is adapted from **“Gorillas — Plain JavaScript Game with HTML Canvas”** by **Hunor Marton Borbely**:

- CodePen: https://codepen.io/HunorMarton/pen/jOJZqvp
- Author repository: https://github.com/HunorMarton/gorillas
- Fixed source commit: `2c9cc51e3bb0425ea0c6bb86ef0b44393c707057`
- CodePen license information: https://blog.codepen.io/documentation/licensing/

The author repository does not include a standalone `LICENSE` file. This port therefore records the CodePen publication and its license entry as the distribution source, while the fixed GitHub commit is used only to make the exact source snapshot reproducible.

The port preserves the original Canvas drawing, skyline generation, gorillas, windmill, projectile physics, AI simulation, hit detection and destructible buildings. AlterU additions include Pointer Events, larger touch targeting, ghost-finger aiming, scoring, platform identity, leaderboard, score-beat notification, responsive product UI, internationalization and audio feedback.
