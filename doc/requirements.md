# Skyline Gorillas 需求文档

## 1. Overview

一局约 20–60 秒的触屏抛物线对战：玩家从屋顶拖拽香蕉炸弹，结合实时风速越过城市击中电脑猩猩；胜利后以命中效率结算积分并进入 AlterU 排行榜。

## 2. Visual Design

- 忠实保留 Hunor Marton Borbely 原作的 Canvas 城市、渐变夜空、月亮、星星、亮窗、风车、两只黑色猩猩、白色香蕉和可破坏建筑。
- 默认采用原作深色模式，标题为 `SKYLINE / GORILLAS`，HUD 使用窄体等宽排版。
- 单指操作由标准 Material 幽灵手指示范一次，示范直接改变原版速度向量和轨迹线。
- 排行榜使用冠军入口与底部全榜弹层；他人行显示圆形头像和名字。

## 3. Game Mechanics

- 每局随机生成 17 栋远景建筑、8 栋前景建筑和 `-10–10` 的风速。
- 投掷按原作物理：每 `elapsed/200` 步叠加风速、`20` 重力并更新旋转。
- 每帧拆成 10 个子步进行城市、屏幕边界和猩猩命中检测。
- 建筑命中产生半径 `18` 的永久爆破孔；下一发可穿过已有孔。
- 电脑第 N 回合运行 `2 + N×3` 次模拟，选择落点最接近玩家的投掷。
- 玩家胜利积分：`max(100, 1200 - (round-1)×120 - blastHoles×25 + round(abs(windSpeed)×8))`。

## 4. Controls

- 单指 / Pointer：从香蕉抓取区按下，向反方向拖拽设置角度和力度，松手投掷。
- 抓取区视觉尺寸 `64×64px`，有效触控目标不小于 44×44px。
- 鼠标使用相同 Pointer Events。
- 首次无人操作时幽灵手指执行一次真实瞄准示范，但不会替玩家投出。

## 5. Win / Lose Conditions

- 玩家香蕉击中电脑猩猩：胜利，计算并提交积分。
- 电脑击中玩家：本局失败，积分为 0，不提交排行榜。
- 结算显示胜负、积分、回合数、“再来一局”和“排行榜”。
- 排行榜只保存个人最高分；新纪录超过另一位用户时只通知最近被超越的一人。

## 6. Sound Effects

- 抓取：`120Hz` 三角波，`0.06s`。
- 投掷：`180→420Hz` 正弦滑音，`0.22s`。
- 建筑爆破：`70Hz` 锯齿波，`0.16s`。
- 胜利：`220/330/495Hz` 三音阶，各 `0.42s`。
- 失败：`180→70Hz` 方波下滑，`0.35s`。
