# Skyline Gorillas 视觉方向

## 视觉承诺

保留原作“夜空中的 QBasic 炮击”气质，不换成通用卡通素材。视觉冲击来自跨越整座城市的抛物线、真实风向、香蕉旋转和建筑被逐步炸穿。

## 色彩

- 夜空顶部：`#58a8d8`
- 夜空底部：`#27507f`
- 远景建筑：`#254d7e`
- 前景建筑：`#152a47`
- 窗光：`#5f76ab`
- 操作与主文字：`#f5f1e7`
- 强调色：`#ffcf58`
- 结算 / 排行榜底：`rgba(245,241,231,.96)`

## 构图与 UI

- Canvas 全屏，标题位于 AlterU 客态安全区下方中央，不加设备外框。
- 两侧 HUD 只显示名字、角度、力度；风速在风车旁显示。
- 冠军入口位于底部左侧，结算板位于中部，不遮挡投掷起点。
- 排行榜全榜从底部进入，列表可滚动；他人行使用头像 + 名字并可打开资料。

## 动效

- 风车转速和方向继续由风速决定。
- 幽灵手指拉出原作白色虚线轨迹，2 秒后淡出并复位。
- 命中时画面闪白 120ms；结算 280ms 淡入上移。

## 反模式

- 不把头像贴到猩猩或建筑上。
- 不用弱小的线代替原作清晰虚线轨迹。
- 不用文字解释单指拖拽；只保留角度、力度和风速信息。
- 不用 Emoji 作为功能图标。
